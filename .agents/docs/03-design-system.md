# 设计系统

## 视觉方向

系统采用明亮的蓝白主色和清晰的信息层次，使用纯白页面背景与轻量蓝灰层次表达分组；蓝色承担主操作与链接，状态色保持语义区分，避免大面积霓虹、粒子尾迹、强烈 3D 和无边界装饰。

## 设计令牌

### 颜色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `color.bg` | `#FFFFFF` | 页面背景（纯白） |
| `color.surface` | `#FFFFFF` | 主容器、侧栏 |
| `color.surfaceRaised` | `#F8FBFF` | 卡片、弹窗 |
| `color.surfaceHover` | `#EDF7FF` | 悬停状态 |
| `color.textPrimary` | `#102F4A` | 标题与正文 |
| `color.textSecondary` | `#48657D` | 辅助信息 |
| `color.textMuted` | `#71869A` | 禁用和元数据 |
| `color.border` | `rgba(31,91,145,0.14)` | 普通边框 |
| `color.borderStrong` | `rgba(31,91,145,0.28)` | 强调边框 |
| `color.accent` | `#1F6FB4` | 主操作、当前状态 |
| `color.accentHover` | `#155995` | 主操作悬停 |
| `color.actionFill` | `#C9E5F8` | 浅蓝主按钮背景 |
| `color.actionFillHover` | `#B2D9F2` | 主按钮悬停背景 |
| `color.actionText` | #12314D | 主按钮文字 |
| `color.actionBorder` | `rgba(31,91,145,0.24)` | 主按钮边框 |
| `color.success` | `#177D63` | 成功、已提交 |
| `color.warning` | `#A56708` | 临近截止、等待文件校验 |
| `color.danger` | `#B63848` | 错误、危险操作 |
| `color.info` | `#1D70B8` | 信息和链接 |

蓝色用于主操作、导航和链接，绿色/琥珀/红色只表达对应状态。文本和背景组合必须达到 WCAG 2.1 AA 对比度。

### 字体

- 中文正文：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 英文与数字：`Inter`。
- 展示标题：`Barlow Condensed`，仅用于页面大标题和赛事标题。
- 代码：`JetBrains Mono`。
- 正文默认 16 px/1.7；数据表 14 px/1.5；辅助文本不小于 12 px。

### 尺寸

- 页面根背景固定为纯白；卡片、侧栏和提示区域使用白色或极浅蓝表面，通过低对比度蓝灰边框与阴影建立层次。

- 内容最大宽度：1440 px；普通阅读正文最大宽度：820 px。
- 间距采用 4 px 基线：4、8、12、16、24、32、48、64。
- 圆角：输入框和按钮 12 px，卡片和容器 16 px，标签 10 px，弹窗最大 20 px。
- 阴影只用于卡片、弹窗和浮层，使用低对比度蓝灰阴影保持层次；边框、背景和圆角共同表达分组。

## 页面骨架

- 侧栏和品牌标识使用统一的内联 SVG 原子图标，底部身份卡显示当前用户姓名与有效角色；折叠时保留图标并隐藏辅助文字。学生提醒徽标必须显示在实际目标业务入口，展开态显示数量，折叠态显示提示点，并通过可读 `aria-label` 说明对应入口未读数。
- 学生端与管理端：共享响应式侧边栏 + 最大 1440 px 主内容；桌面详情页可采用 8/4 栅格放置正文和状态侧栏。
- 管理端：240 px 左侧栏 + 主工作区；低于 1024 px 时侧栏收为抽屉。
- 断点：移动端 `<768`，平板 `768–1023`，桌面 `>=1024`。
- 所有关键流程在 360 px 宽度下可完成，禁止只通过悬停暴露操作；窄屏侧边栏使用抽屉打开。

## 组件规范

- 面板、导航和认证表单优先使用白色表面、蓝灰边框及低对比度阴影；同一操作区的主按钮、次要按钮和状态标签保持层级区分。
- 图标使用统一的内联 SVG 原子组件，图形承担识别作用，导航名称和按钮文字继续保留为可读标签。
### 按钮

- Primary：浅蓝底深蓝字，带轻微阴影和 12 px 圆角，每个操作区最多一个，用于提交、发布、标记和“新建”主动作。深蓝底仅用于状态标签，不与主按钮混用。
- 管理端列表页命令栏沿用 `management_system` 模板的紧凑按钮规格：高度 36 px、8 px 圆角、浅蓝底深蓝字，并保留可见焦点与悬停反馈；表单主按钮仍使用 40 px 高度和 12 px 圆角。
- `Secondary`：白色或浅蓝表面和蓝灰边框，用于保存草稿、预览和次要动作。
- `Ghost`：无背景，用于返回、取消和行内操作。
- `Danger`：危险红，仅用于禁用、撤回、解散等需要确认的操作。
- 高度 40 px，移动端触控区域至少 44×44 px；加载时保持宽度、显示进度并禁用重复提交。

### 输入与表单

- 标签始终可见，不用占位符代替标签。
- 必填、帮助文本和错误文本紧邻字段；错误使用颜色、图标和文字共同表达。
- Markdown 编辑器在编辑表单中提供源文本；已保存作业编辑页默认先展示与学生相同的安全 HTML，源文通过明确按钮按需展开；非编辑页面只展示服务端安全 HTML，不显示内部实现标签。
- 日期时间输入显示 `Asia/Shanghai`，提交前回显完整日期、时间和时区。
- 保存草稿与正式发布/提交严格区分，正式操作使用确认摘要。

### 卡片、列表与表格

- 学生内容卡片突出状态、截止时间和单一下一步动作。
- 管理端优先使用表格；窄屏切换为字段标签明确的卡片。
- 可排序列显示方向；筛选条件以可移除标签展示；批量操作只在明确选择后出现。
- 空列表显示原因和下一步，不展示虚假示例数据。

### 培训文档阅读器

- 登录态 `AppShell`、当前蓝白令牌和服务端页面守卫保持不变；同步顺序、块转换与失败语义继续以参考仓库提交 `c28f8a0` 为准，阅读器当前页面布局与交互由 ADR-034 约束。
- 内容区使用纯白或极浅蓝表面、深色正文、蓝灰边框和蓝色交互强调；顶部展示英文眉题、知识库标题、文档数和同步时间，不存在顶部文档切换栏。桌面从左到右依次为可折叠的 280 px 文档目录、弹性正文和正文右侧可折叠的 180 px 本文目录。
- 文档标题搜索只筛选目录；当前文档使用系统统一的浅蓝表面、蓝灰边框和文字层级标识。目录行、搜索框、标题栏及展开/收起按钮复用全局令牌、圆角、阴影、悬停和键盘焦点规范。无当前文档时只展示根层条目，根文件夹显示向右箭头并保持收起；显式进入文档后才自动展开其祖先链并滚动定位活动项，切换文档后旧自动路径收缩，退出到无文档首页时恢复根层收起视图，目录栏整体开合仍由用户控制。成功打开当前或其他文档后折叠系统最左侧主要导航；加载失败不改变当前文档、目录树和主导航。移动端用右下固定“目录”按钮打开全屏目录，目录内同时包含搜索、目录树和当前文档标题导航，选中后关闭弹层。
- 右侧本文目录使用视口吸附和最大视口高度，长目录内部滚动；页面滚动时当前章节使用 `aria-current="location"`、浅蓝背景和强调文字同步标识。任何祖先容器不得使用会阻断 sticky 的滚动容器样式。
- 代码和表格在窄屏可横向滚动，不撑破页面；连续图片使用容器宽度驱动的自动并排与换行。图片点击在当前页高层遮罩中等比预览，支持 Escape、关闭按钮、遮罩关闭和焦点回归，不打开新页面。目录独立文件使用带文件大小/媒体类型的紧凑行与站内“下载”按钮；失败资源只显示“暂不可下载”。受控资源路径不得暴露内部对象键、飞书链接或媒体令牌。

### 状态标签

- 中性：草稿、归档、撤回。
- 信息：已发布、报名中、提交中、反馈答疑待处理。
- 成功：已验证、已激活、已提交、队伍有效、反馈答疑已解决。
- 警告：待邮箱验证、临近截止、邮件重试。
- 危险：禁用、拒绝、逾期、队伍无效、邮件最终失败。
- 标签文字使用面向用户的中文，不直接暴露数据库枚举。
- 账号管理固定显示“正常 / 待验证 / 已禁用”胶囊标签，以低饱和绿 / 琥珀 / 红边框、浅色背景、状态圆点和文字共同表达；角色标签使用低饱和蓝灰样式，不能与账号状态争夺视觉层级。

### 反馈答疑工单

- 学生列表首屏同时展示创建表单、本人最近工单和已解答的“公开答疑”；类型使用“系统反馈 / 问题答疑”中文标签，状态使用“待处理 / 已解决”，不得直接展示数据库枚举。
- 详情页按“学生提交内容 → 当前状态 → 管理员处理结果/答复”呈现；无答复时明确显示等待处理，不渲染评分或聊天占位。
- 管理员答复表单与工单身份摘要相邻，提交中禁用重复操作；修订成功后刷新服务端权威详情，冲突提示重新载入而不覆盖他人答复。
- 公开答疑卡片和详情只展示问题、答复与时间，不展示作者占位、头像或任何可反推身份的信息；页面明确标注“解答后匿名公开”。
- 系统反馈使用“仅本人和管理员可见”提示；问题答疑使用“解答前私密，管理员解答后匿名公开”提示。

### 弹窗与确认

- 删除、禁用、取消优秀标记、提前关闭和管理员修改锁定队伍必须确认。
- 确认弹窗说明影响对象、不可逆部分和后续恢复方式；需要原因的操作提供必填文本框。
- 普通信息使用非阻塞提示，不用弹窗替代页面级错误。

### 上传器

- 显示文件名、大小、分片进度、速度、剩余时间、校验状态和重试/终止操作。
- 浏览器刷新后通过上传会话恢复；已成功分片不重复上传。
- 正式提交前显示本版本附件合计和 2 GiB 上限。
- 上传成功不等于正式提交；两种状态在文案和颜色上明确区分。

### 时间与截止状态

- 大于 72 小时显示完整截止时间。
- 72 小时内同时显示相对时间和完整时间。
- 截止后使用“已截止”，若存在个人延期则明确显示“个人延期至”。
- 不用纯颜色表达紧迫程度。

## Markdown 正文

- 正文宽度不超过 820 px，标题层级从页面标题后的 `h2` 开始。
- 支持标题、段落、加粗、斜体、列表、引用、表格、链接、图片和代码块。
- 外链显示外部链接图标并使用 `rel="noopener noreferrer"`。
- 禁止原始 HTML、iframe 和可执行内容；代码块横向滚动，不撑破布局。
- 管理员预览、学生详情和邮件摘要使用一致的文本语义，邮件不直接发送完整私密 Markdown。

## 加载、空状态与错误

- 初次加载使用与最终布局一致的骨架屏，避免大幅跳动。
- 写操作显示局部进度；成功提示说明实际结果，例如“已发布，邮件正在后台发送”。
- 字段校验错误保留已填写内容并聚焦第一个错误。
- 页面级错误展示请求 ID、重试按钮和安全返回入口。
- 离线或网络中断时暂停上传并保留会话，不误报提交成功。

## 动效

- 持续 180–280 ms，允许淡入、轻微位移、线条展开和进度变化。
- 尊重 `prefers-reduced-motion`，关闭非必要位移与自动滚动。
- 禁止让动画延迟发布、提交、反馈和错误展示。

## 无障碍

- 所有交互可通过键盘完成，焦点顺序与视觉顺序一致。
- 焦点环使用 2 px 高对比描边，不因视觉美化移除。
- 弹窗、抽屉和菜单正确管理焦点并支持 Escape 关闭。
- 表格提供表头语义；图标按钮提供可读名称；状态变化通过 `aria-live` 适度播报。
- 上传进度使用 `progressbar` 语义；错误不能仅靠颜色区分。

## 需求映射

本设计系统支撑 NEWS-001、HW-001、SUB-001～SUB-004、COMP-001～COMP-004、KB-001～KB-003、KB-005、KB-007～KB-008、HELP-001～HELP-007、SHOW-001～SHOW-005、FILE-001～FILE-007，以及 NFR-004、NFR-010、NFR-011。
