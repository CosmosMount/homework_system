# 页面规格

## 通用约定

- 所有业务页面在服务端确认 Session；未登录跳转 `/login`，不可见资源统一显示 404。
- 页面首次读取使用服务端数据，筛选、表单、上传和局部刷新使用客户端组件。
- 页面错误必须展示请求 ID；危险操作必须二次确认并在成功后刷新权威服务端数据。
- 每个列表提供加载、空、错误和分页状态；筛选写入 URL 查询参数。

## 全局登录后布局

- 所有学生和管理员业务页面使用共享响应式侧边栏；桌面端固定在左侧并可折叠，窄屏通过“打开主要导航”进入侧边抽屉。
- 当前路由在侧边栏中标记为 active；侧边栏只负责导航展示，所有页面和 API 权限仍由服务端鉴权。
- 个人资料、登录设备和退出操作位于侧边栏底部；学生未读提醒按业务目标分别显示在通知、作业、校内赛和反馈答疑入口；已读或已归档公告提醒不显示。
- 管理员真实角色为 `admin` 时，侧栏底部显示“查看学生视图”；开启后同一位置改为“返回管理员视图”。切换通过带 CSRF 的认证接口完成并刷新当前路由，学生视图只显示学生导航；服务端页面守卫仍按有效角色拒绝 `/admin/*`。

## 认证页面

### 登录 `/login`

- **目标**：为激活用户创建普通或可选持久 Session；对应 AUTH-004、AUTH-006、AUTH-009、AUTH-013。
- **组件**：用户名或校园邮箱、密码、显示密码、默认关闭的“记住登录状态”、登录按钮、注册链接、忘记密码。
- **行为**：Connect 用户可以输入邮箱 `@` 前缀或完整邮箱，旧域名存量用户必须输入完整邮箱；成功后按持久化角色跳转。若该用户是系统唯一的已验证 active 账号，登录事务先保证其为管理员，再跳转管理概览。账号不存在、密码错误、待验证和禁用状态统一显示登录失败文案，不通过登录接口暴露账号状态；已验证 active 账号输入正确密码时直接登录，不受此前失败事件的持久冷却阻断。未勾选时只设置浏览器会话 Cookie；勾选时明确提示“仅私人设备和当前网络、最多 30 天、不保存密码”，有效 Cookie 与登录时精确来源 IP 绑定匹配才可免重复登录，网络变化后重新登录。注册成功页和独立重发验证入口负责提示查收邮件。
- **异常**：无效登录达到应用层阈值时进入 10 分钟重试窗口，429 显示重试时间；瞬时入口超限也可返回 429。网络失败保留登录标识但清空密码。
- **移动端**：单列、无装饰侧栏，键盘弹出时主按钮仍可见。

### 注册 `/register`

- **目标**：创建 `@connect.hkust-gz.edu.cn` 学校邮箱账号；对应 AUTH-001～AUTH-003、AUTH-008、AUTH-010。
- **组件**：真实姓名、学号、校园邮箱、密码、确认密码、密码规则、隐私提示。
- **行为**：客户端即时提示格式，服务端统一校验 8～128 个字符、常见密码及身份相似性，并精确校验 Connect 邮箱后缀和唯一性；成功后展示由邮箱前缀派生的用户名、查收邮件说明和“完成验证前不能登录”。验证成功即激活，空系统首个验证账号成为管理员，其余账号成为学生；后续学生在同一激活事务获得当时仍开放且匹配的作业。
- **异常**：重复邮箱/学号使用对应输入框的明确字段错误，包括并发写入最终由数据库唯一约束拒绝的情况，不得显示通用“服务暂时无法处理请求”；注册与“重新发送验证”不设置应用层持久失败窗口，重发接口不暴露账号是否存在。

### 邮箱验证与密码流程

- `/verify-email` 消费一次性令牌，成功后直接激活账号并提供登录入口；空系统首个激活账号由事务唯一授予管理员角色，过期时允许重新发送。
- `/forgot-password` 始终返回统一成功提示，且不设置应用层持久失败窗口。
- `/reset-password` 验证令牌后按与注册一致的 8～128 字符密码策略设置新密码，成功撤销其他 Session 并跳转登录。
- 对应 AUTH-002～AUTH-005、AUTH-009。

## 学生工作台 `/dashboard`

- **目标**：把未读通知、待交作业和进行中赛事集中为可执行清单。
- **数据**：当前用户、有效未读总数与按入口分类计数、最近通知、按最早截止排序的作业、我的赛事/队伍。
- **组件顺序**：问候与身份标签、重要通知、近期截止、我的赛事。
- **空状态**：无任务时显示“当前没有待办”，仍保留通知与作业入口。
- **权限**：只返回当前受众和当前团队数据；对应 NEWS-005、HW-006、TEAM-006。
- **移动端**：所有模块单列，截止时间和主操作在首屏可见。

## 通知

### 列表 `/announcements`

- **目标**：查看与本人相关的已发布、未归档通知；对应 NEWS-003～NEWS-005、NEWS-008。
- **组件**：关键词搜索、未读筛选、置顶区、时间线式列表、分页。
- **卡片字段**：标题、摘要、发布时间、置顶标签、附件标记和已读状态。
- **行为**：打开详情后通过受保护写接口标记该公告相关提醒已读；批量全部已读需要确认当前筛选范围，公告归档后相应未读徽标立即消失。

### 详情 `/announcements/[announcementId]`

- **数据**：标题、发布时间、更新标记、清洗后的正文、附件、受众描述和上下篇导航。
- **权限**：学生必须属于受众；管理员可以预览任意状态。
- **附件**：下载前请求授权地址；外部 URL 不直接暴露对象键。
- **错误**：非受众、不存在和已归档通知均为 404；对应 NEWS-001、NEWS-007～NEWS-009、FILE-005。

## 作业与个人提交

### 作业列表 `/assignments`

- **目标**：查看正式受众快照包含自己且未归档的作业；新学生激活时会补入仍开放且匹配的作业，删除/归档后从全部筛选中立即消失；对应 HW-002～HW-003、HW-006、HW-008。
- **筛选**：待提交、已提交、已截止、全部和关键词；受众由服务端限定。
- **卡片**：标题、技术方向标签、公共/个人截止时间、最新版本、评语未读和主操作。
- **排序**：未截止按有效截止时间升序，已截止按截止时间倒序。

### 作业详情 `/assignments/[assignmentId]`

- **目标**：阅读要求、查看本作业优秀作业并创建新版本；对应 HW-001、HW-004、HW-006、SUB-001～SUB-004、SHOW-001～SHOW-005、FILE-001～FILE-007。
- **主区**：说明、培训资料外链、提交要求、允许类型、Markdown 文本、链接输入、附件上传器，以及位于提交区之后的“优秀作业”区块。
- **侧栏**：状态、公共截止、个人延期、最新版本、附件合计、提交按钮。
- **正式提交**：先完成上传与校验，再显示确认摘要；确认后创建不可变版本并进入版本详情。
- **截止状态**：截止后表单只读；存在个人延期时使用个人时间。上传完成但未正式提交的文件不显示为已提交。
- **恢复**：刷新后使用上传会话 ID 恢复分片；表单文本仅保存在本地草稿，正式版本以服务端为准。
- **优秀作业**：只列出本作业被管理员标记的版本，显示提交者姓名、文本、链接和授权附件；不显示私密评语或其他版本。
- **删除可见性**：作业归档删除后，学生详情与作业内优秀作业列表/详情统一进入 404；本人已形成的不可变提交历史继续按留存策略保存，不通过作业列表重新暴露入口。

### 版本与评语 `/assignments/[assignmentId]/submissions/[submissionId]`

- **目标**：查看个人版本历史和私密评语；对应 SUB-003、SUB-005～SUB-008。
- **组件**：最新版本摘要、版本切换、文本/链接/附件清单、提交时间、对应评语、创建新版本入口。
- **权限**：仅提交所有者和管理员；学生不能删除、修改或比较他人版本。
- **空反馈**：显示“管理员尚未反馈”，不显示评分占位。

### 优秀作业详情 `/assignments/[assignmentId]/excellent-submissions/[versionId]`

- **目标**：在作业上下文中阅读一份优秀作业；对应 SHOW-001～SHOW-005。
- **数据**：作业标题、提交者姓名、被标记版本的文本、链接、附件和标记时间。
- **权限**：当前学生必须属于该作业受众；管理员始终可查看。版本未被标记、已取消标记或属于赛事时返回 404。
- **隐私**：不请求或渲染私密评语、内部审计和源提交的其他版本。

## 赛事与队伍

### 校内赛队伍中心 `/competitions`

- **目标**：只展示当前未归档校内赛的公告、报名和队伍状态；对应 COMP-001～COMP-003、TEAM-001、TEAM-008。
- **模块**：当前校内赛摘要、报名/创建队伍/邀请码加入/自动分配操作，以及可按名称搜索和分页的队伍目录。
- **队伍目录**：只列出未满的成形队伍，卡片只展示队伍名称、状态、当前/最大人数和能否加入，不返回成员姓名、学号或邀请码；空结果提示创建、邀请码和自动分配三种恢复路径。
- **自动分配**：仅已报名且无队伍学生看到入口；加入现有队伍时提示分配结果，自动建队时显示只出现一次的邀请码。

### 赛事详情 `/competitions/[competitionId]`

- **目标**：阅读校内赛公告、报名并进入队伍；对应 COMP-001～COMP-003、COMP-006、TEAM-001～TEAM-005、TEAM-008。
- **模块**：赛事公告、时间轴、规则链接、报名状态和我的队伍摘要。
- **报名期**：未报名显示报名按钮；已报名且无队伍显示创建队伍和输入邀请码。
- **报名结束后**：展示队伍锁定状态；无效/取消资格队伍显示联系管理员说明。
- **个人取消资格**：仅被取消资格的本人显示管理员填写的个人原因；其他学生不得读取该原因。若其仍在队内，队伍只显示不泄露个人原因的通用取消资格说明。
- **归档**：所有操作只读，不展示排名区域。

### 我的队伍 `/competitions/[competitionId]/team`

- **目标**：完成建队、邀请、成员与队长管理；对应 TEAM-001～TEAM-007。
- **组件**：队伍名、状态、人数要求、成员列表、队长标记、邀请码操作和审计后的管理员变更提示。
- **队长操作**：轮换邀请码、移除成员、转让队长、解散队伍；锁定后全部隐藏。
- **成员操作**：报名期退出；队长未转让时不能退出。
- **并发冲突**：加入已满或已加入其他队伍时显示 409 对应的明确恢复路径。

## 学生问卷

### 列表 `/intentions`

- 展示当前 `open` 且处于填写时间窗口内的问卷，卡片标记题目数、每人提交上限、本人已提交次数、截止时间和是否已达上限；对应 INT-001～INT-004。
- 不展示已关闭、已归档或他人答案；无开放问卷时显示只读空状态。

### 填写 `/intentions/[surveyId]`

- 展示清洗后的 Markdown 说明和按顺序排列的多道必答单选/多选题，载入本人最新答案、补充说明和已提交次数；保存使用 `PUT` 覆盖本人最新回答并消耗一次提交，达到上限后控件与按钮只读。
- 二维码 `token` 仅作为查询参数定位问卷；未登录时跳转 `/login?next=...`，登录成功后安全返回原问卷和 token。无效或轮换前 token 返回 404；对应 INT-002～INT-006。
- 移动端单列完成全部题目、补充说明和提交；表单显示剩余次数，可键盘操作，错误与成功状态使用可访问提示。

## 反馈答疑

### 本人工单与创建 `/help`

- **目标**：提交系统反馈或问题答疑，查看本人历史记录和已解答匿名公开答疑；对应 HELP-001～HELP-002、HELP-006～HELP-007。
- 首屏先提供类型、标题和详情表单，详情支持安全 Markdown；类型选择为系统反馈时提示始终仅本人和管理员可见，选择问题答疑时提示解答前私密、管理员解答后匿名公开。正式提交按钮显示进行中状态并阻止重复提交，成功后进入新工单详情。
- 本人工单列表按创建时间倒序，支持类型、状态和分页；卡片显示中文类型、标题、“待处理 / 已解决”、创建时间和是否已有管理员答复，无记录时保留创建入口。
- 公开答疑区域分页展示已解答问题的标题和解答时间，链接到公开详情；不显示提问者身份或作者占位。

### 本人工单详情 `/help/[requestId]`

- 展示类型、标题、创建/更新时间、安全清洗后的提交详情和管理员处理结果/答复；无答复时明确显示“管理员尚未处理”。打开已解决的本人工单详情后，通过受保护写接口只把该工单相关解决提醒标为已读，其他工单提醒保持不变。
- 当前学生只可通过本人接口读取本人记录，不提供编辑、删除、评论、附件、关闭或手动公开操作；越权与不存在统一进入 404。
- 管理员学生视图按本人账号使用同一页面；普通管理员视图访问学生入口时跳转管理员反馈答疑管理。

### 公开答疑详情 `/help/public/[requestId]`

- 有效登录用户可查看已解决问题的安全问题正文和管理员最新答复；页面只展示匿名内容、状态与时间，不展示提问者 UUID、姓名、学号、邮箱或作者占位。
- 待解答问题、系统反馈和不存在记录统一进入 404；匿名访问先进入登录页。页面不提供评论、追问、附件、点赞或评分。

## 培训文档

### 阅读器 `/knowledge`

- **目标**：学生和管理员读取最后一次成功的培训知识库快照；对应 KB-001～KB-003、KB-005、KB-007。
- **参考契约**：同步顺序、块转换与失败语义继续固定对齐参考仓库提交 `c28f8a0`；页面主题、目录位置、滚动跟随和打开文档后的主导航行为按 ADR-034 执行。保留本平台登录态 `AppShell`、受保护 API 和资源 UUID，不复制参考官网的公开路由或全站外壳。
- **顶部与主题**：使用白色主题和深色文字，先显示知识库眉题、标题、文档数和最近同步时间，再进入目录与正文区域；不存在额外的顶部文档切换栏。
- **目录**：桌面左侧为可折叠 280 px 文档目录与标题搜索，正文右侧为可折叠 180 px 本文目录，DOM 与视觉顺序为“文档目录—正文—本文目录”。无有效 `?doc` 时不自动加载第一篇文档，只展示根层条目且根文件夹保持收起；显式打开文档时只自动展开其祖先链，活动项滚入目录可视区域，切换后旧自动路径收缩，浏览器历史返回无文档首页时恢复根层收起视图。目录栏整体开合保持用户状态。右侧本文目录随页面滚动吸附、长目录内部滚动，并按当前阅读标题设置 `aria-current="location"`。当前文档写入 `?doc=<uuid>`，刷新和浏览器前进/后退可恢复；成功打开当前或其他文档后折叠系统主要导航，加载失败时保留当前文档、目录树和主导航。文档目录与所有目录按钮复用系统统一控件样式。
- **移动端**：右下固定“目录”按钮打开全屏目录；同一目录内展示搜索、目录树和当前文档本文目录，选中文档或标题后关闭。
- **正文**：按参考结构渲染富文本、连续列表、引用、代码语言与复制、提示块颜色/Emoji、合并单元格表格、连续图片画廊、白板和附件；连续图片在容器足够宽时并排、空间不足时换行，空段落和只含媒体的结构容器不打断同一画廊，可见段落、标题、列表等继续作为分组边界；图片点击在当前页可访问模态浮层预览并支持 Escape/遮罩/按钮关闭，不打开新页面。飞书富文本 `equation` 显示为行内公式，`block_type=16` 显示为独立公式，解析失败保留可读 LaTeX 源文。显式映射到当前快照的内部文档 mention 在当前阅读器切换；普通 HTTPS 外链继续新窗口打开。真实学生和管理员学生视图不显示标题下的飞书原文入口，也不把未映射飞书文档 URL 渲染为链接；真实管理员普通视图保留原文入口。
- **媒体**：本地媒体只使用登录态 `/api/v1/knowledge/assets/{id}/content`，由后端授权后跳转短时 MinIO URL；成功本地化的块附件、富文本内嵌文件和目录 `file` 节点均可下载，目录行显示安全文件大小与媒体类型。图片或白板本地化失败跳过对应块；正文附件失败时真实学生和管理员学生视图显示“暂不可下载”且不生成飞书链接，真实管理员普通视图可使用既有“在飞书查看”回退；目录独立文件失败在所有学生阅读路径只显示不可下载状态。
- **状态**：无成功快照显示等待管理员首次同步；单篇加载失败保留目录和当前文档，不清空已有成功快照。

### 管理页 `/admin/knowledge`

- 使用 `AdminPageHeader` 展示配置状态、学生当前版本和最近同步运行；真实管理员可点击“立即同步”创建 `202` 异步任务，并手动刷新状态。
- 已有 `pending/running` 任务时禁用按钮且后端返回 `409 KNOWLEDGE_SYNC_IN_PROGRESS`；未配置返回 `503 KNOWLEDGE_SYNC_NOT_CONFIGURED`。
- 页面不显示 app secret、tenant token、对象键或飞书响应正文；管理员学生视图访问时由管理守卫拒绝。对应 KB-004～KB-008。

## 个人资料

### `/profile`

- 展示姓名、学号、学校邮箱、可选技术方向和账号状态；未设置方向时明确显示“未设置”。
- 管理员可以在本页维护自己的姓名、学号和校园邮箱；修改邮箱会撤销当前 Session 并要求重新验证。学生不能自行修改学号、学校邮箱、技术方向或角色。届次不再展示或编辑。
- 管理员处于学生视图时按学生界面展示只读资料，不显示管理员资料编辑器；返回管理员视图后恢复编辑入口。真实角色降级导致 Session 撤销后，页面必须回到登录流程，不提供恢复管理员的客户端操作。
- 学生和管理员都看到独立红色“注销账号”区：说明账号/个人数据立即物理删除、共享记录和团队版本去除归属后保留、MinIO 对象异步清理、备份保留期仍可能存在历史副本。表单要求当前密码、与本人邮箱精确匹配的确认输入和不可撤销确认 checkbox；密码只在当前 DOM 内存中存在，后端失败后清空密码框。
- 成功注销返回 `204`、清理 Session/CSRF Cookie 与前端 CSRF 缓存，并替换导航到 `/login?account_deleted=1`；失败保留说明与非密码输入。最后一名激活管理员注销时显示服务端冲突，账号保持不变。
- 修改邮箱需要管理员操作并重新验证；账号注销对应 AUTH-012，其余资料对应 AUTH-007、AUTH-010。

### `/profile/sessions`

- 展示当前和其他 Session 的创建时间、最近活动、IP 摘要和设备摘要。
- 用户可以撤销其他 Session，不能在未确认时撤销当前请求上下文；对应 AUTH-006。

## 管理后台

### 概览 `/admin/dashboard`

展示未验证账号数量、未来 72 小时截止作业、无效队伍、最终失败邮件、近期审计和存储容量告警。每个指标链接到已带筛选条件的对应列表。

### 用户与方向

- `/admin/users` 默认分页覆盖所有状态、方向和角色的账号，固定每页 20 条并显示本页数量、匹配总数、当前页和总页数；上一页/下一页保留搜索与活跃度筛选，因而可逐页查看全部账号。搜索通过 URL `search` 提交到服务端，在分页前对全体账号的姓名、邮箱、学号以及中文/英文角色和状态执行匹配，不得只过滤当前页。页码限制为 1～10000；取得匹配总数后，超出实际总页数的 URL 带原筛选回到末页。页面继续支持禁用、恢复、方向维护和 `student/admin` 角色调整；初始管理员使用同一界面，不提供注册批准、拒绝或重开审核。
- 用户卡片把 `active`、`pending_email`、`disabled` 分别显示为“正常”“待验证”“已禁用”中文胶囊标签，不直接暴露数据库枚举；角色使用独立的蓝灰标签，超过十天未进入显示紧凑时钟提示。搜索同时接受中文角色和状态名称。
- 每个账号卡片提供与其他高风险操作分离的“永久删除账号与个人数据”表单，适用于近期活跃、待验证和已禁用账号。表单要求去空白后至少 3 字符的内部原因、当前管理员密码、目标账号邮箱和“近期 PostgreSQL 与 MinIO 加密备份可恢复”checkbox；页面明确说明确认不替代实际备份、共享记录/团队版本保留及对象异步清理。
- 管理接口拒绝删除当前操作者并引导到个人资料页，拒绝删除最后一名激活管理员；失败后账号卡片保留并清空密码。资料、角色、状态或删除写入成功后按当前 URL 重新获取服务端结果，以重新应用搜索/活跃度条件并补齐因 OFFSET 变化前移的账号；删除使当前页越界时回到新的末页。前端隐藏或按钮状态均不替代后端鉴权、重新认证和事务锁。
- `/admin/categories` 仅管理技术方向名称、编码和启用状态；历史届次记录不再提供产品入口，数据库与旧 API 暂保留。
- 对应 AUTH-007、AUTH-008、AUTH-010、AUTH-012。
- `/admin/sessions` 仅管理员可见，展示当前活跃登录人员、角色、设备摘要、IP 网段和最近活动时间，不返回 Cookie 或 Session 令牌。

### 通知管理

- 列表只显示未执行删除的通知，并展示状态、受众、发布时间、预计/实际接收数和邮件结果；手工归档通知继续作为可管理留存记录显示。
- 创建/编辑页包含 Markdown、附件、受众构建器、发布计划、置顶和邮件开关。
- 发布确认展示接收人数；更新提醒是独立动作，避免编辑即群发。
- 已保存且未删除的通知都提供“删除通知”：草稿/定时通知提示永久删除并取消定时任务，已发布或手工归档通知提示从学生端和管理页隐藏但保留历史；归档页不再显示保存、发布或更新提醒操作，删除成功后返回通知管理列表。
- 对应 NEWS-001～NEWS-009、MAIL-002～MAIL-005。

### 作业与提交管理

- 作业表单包含可编辑的 Markdown 说明、受众、外部资料、附件规则、发布时间和截止时间；已保存说明使用与学生详情相同的服务端安全 HTML 展示，不呈现内部实现标签。
- 作业列表只显示未执行删除的作业；手工归档作业继续显示为可管理留存记录。作业详情展示受众快照和提交统计，可为个人延期。
- `/admin/submissions/[submissionId]` 展示版本并写私密评语；作业版本可直接标记或取消“优秀作业”，赛事版本不显示该操作。
- 已保存且未删除的作业提供“删除作业”：草稿提示永久删除并取消定时任务，已发布、已关闭或手工归档作业提示从学生端和管理页隐藏并保留提交、评语、优秀标记和附件；成功后返回作业管理列表。
- 对应 HW-001～HW-008、SUB-006～SUB-008、SHOW-001～SHOW-005。

### 赛事与队伍管理

- `/admin/competitions` 固定展示当前未归档的“校内赛”和队伍列表；页面不提供“新建赛事”，队伍卡片进入纠错详情。
- `/admin/competitions/new` 仅在系统尚未配置当前校内赛时作为首次配置兼容入口；已有当前赛事访问该路由返回校内赛管理页。
- `/admin/competitions/[competitionId]` 的赛事表单定义校内赛公告、阶段时间和人数限制，并展示个人报名记录与队伍状态。
- 管理员可对个人报名执行带原因的取消资格；原因只对管理员和该学生本人可见，学生不能重新报名，仍在有效队伍时整队同步取消资格但仅显示通用团队原因。
- `/admin/competitions/[competitionId]/teams/[teamId]` 展示成员，允许带原因的补录、移除、队长变更、人数豁免、取消资格和删除；所有操作审计。删除使用独立危险区和二次确认：无历史团队提交时永久删除队伍及成员关联，已有历史提交时释放当前成员并保留不可变版本、评语和附件。
- 管理员移除成员导致已锁队伍低于最低人数时自动转为 `invalid`；补录达标或人数豁免可恢复为 `locked`。
- 删除成功后返回 `/admin/competitions`；被删除队伍从学生“我的队伍”、公开目录、常规管理员队伍列表和直接详情退出，不存在或已保留为 `dissolved` 的详情统一 404。失败时保留当前页、原因和统一 API 错误。
- 历史赛事提交详情按兼容接口只读；新赛事不创建作品提交或评语。
- 对应 COMP-001～COMP-006、TEAM-004～TEAM-005、TEAM-008～TEAM-009。

### 问卷管理 `/admin/intentions`

- 使用统一 `AdminPageHeader`，创建区填写问卷标题、Markdown 说明、每人提交上限，并动态增加/删除题目；每题填写题目、逐行选项和单选/多选配置。草稿可开放，开放问卷可关闭，已关闭问卷同时提供“重新开启”和“归档问卷”，已归档问卷不再提供状态操作。
- 每份问卷提供“查看内容”，按题序显示 Markdown 源说明、时间窗口、提交限制、单选/多选类型及全部选项；`draft` 额外提供编辑入口，可整体修改上述字段并使用 revision 防止覆盖其他管理员的新版本。开放、关闭、重新开启或归档后内容均只读，重新开启不重置既有回答、累计次数或二维码 token，并继续受原时间窗口和提交上限约束。
- 每份问卷可刷新分题汇总，展示有效学生数、提交人数/比例和各题各选项人数/比例；“查看提交名单”展示姓名、学号、学校邮箱、最新答案、补充说明、累计提交次数和最后提交时间，仅管理页面调用。
- `draft/open` 问卷可生成移动端二维码；二维码在浏览器内本地生成，不调用第三方服务，重生成后旧 token 失效。关闭期间不显示生成入口，重新开启后原 token 恢复定位能力且可由管理员再次生成并轮换；归档后不再显示生成入口。对应 INT-001～INT-006。
- `open` 问卷卡片提供“发送邮件通知”，范围单选为“手动选择成员”“按技术组”和“全部激活学生”。手动模式通过既有成员搜索按姓名、学号或学校邮箱查找并勾选最多 100 人；技术组模式只列出激活技术组并要求选择一个；全部模式明确提示将按发送时的全部激活学生创建任务。未满足当前范围输入时按钮禁用，成功提示新增入队与同开放周期已存在数量；关闭/归档问卷不显示发送区。浏览器不得提交任意邮箱，且技术组/全部模式不得自行展开成员 UUID。对应 INT-007、MAIL-001～MAIL-005。

### 反馈答疑管理 `/admin/help`、`/admin/help/[requestId]`

- 使用统一 `AdminPageHeader`，列表按类型、状态和关键词筛选并分页，显示学生姓名、学号、工单类型、标题、状态、创建与解决时间；默认优先查看待处理工单。
- 详情展示学生姓名、学号、学校邮箱、原始安全内容和当前答复。答复表单要求非空 Markdown，提交时携带当前 revision；首次答复把状态变为“已解决”，后续修订保留已解决状态。问题答疑明确提示保存后自动匿名公开，系统反馈明确提示始终私密。
- revision 冲突时提示重新载入，不覆盖其他管理员的新答复；成功后刷新权威详情，站内提醒只含标题和学生详情链接。
- 详情页提供“删除问题答疑 / 删除系统反馈”危险操作并二次确认，明确工单会从学生本人记录及公开答疑永久移除且无法由应用恢复；成功后返回管理列表，失败保留当前页并显示统一 API 错误。
- 学生及管理员学生视图由服务端管理守卫拒绝；页面不提供手动公开开关、附件、评分、自动回复或多轮聊天。对应 HELP-003～HELP-008。

### 邮件与审计

- `/admin/mail` 展示 Outbox 状态、事件类型、接收方掩码、尝试次数、下次重试、最终错误和人工重试。
- `/admin/audit` 按操作者、动作、资源、请求 ID 和时间过滤，只读且不提供删除。
- 对应 MAIL-002～MAIL-005、NFR-006。

## 页面与 API 的数据边界

- 页面不得直接拼接 MinIO URL，必须通过上传和下载 API 获取短时授权地址。
- 管理端“查看学生视图”不模拟学生身份；需要验证受众时使用服务端预览结果。
- 前端可以缓存列表读取，但完成写操作后必须使相关缓存失效并重新读取服务端状态。
- 密码、认证一次性令牌、邀请明文、私密评语和问卷个人答案不进入客户端持久化状态、日志或分析事件；问卷二维码 token 只在生成响应和当前页面内存中短暂显示。
