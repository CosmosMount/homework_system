# 测试策略

## 目标

测试不仅验证页面能用，还必须证明权限、状态、截止、并发、文件校验、隐私和异步任务符合需求。每个缺陷修复先增加能复现问题的测试，再修改实现。

## 测试层级

| 层级 | 工具方向 | 重点 |
| --- | --- | --- |
| 后端单元 | Pytest | Service 状态机、权限、截止、受众、重试与纯函数 |
| 后端集成 | Pytest + 临时 PostgreSQL/MinIO | Repository、约束、事务、预签名、Outbox、迁移 |
| 前端单元 | Vitest + Testing Library | 表单、状态呈现、上传器、无障碍语义 |
| API 契约 | OpenAPI schema + 集成测试 | 请求/响应、错误结构、权限和幂等 |
| 浏览器端到端 | Playwright | 真实注册、邮箱验证直达登录、通知、提交、组队、评语和优秀作业流程 |
| 性能 | k6 或同等工具 | 300 账号基线、100 浏览会话、20 并发分片上传 |
| 安全 | 依赖扫描、静态检查、针对性渗透用例 | XSS、CSRF、会话、越权、对象访问和枚举 |
| 运维验证 | 隔离 Compose 环境 | 健康、备份、恢复、迁移和更新回滚 |

测试依赖必须固定版本并在 CI 中可重复运行。集成测试使用真实 PostgreSQL 和兼容 MinIO，不用 SQLite 替代数据库约束。

## 单元测试重点

- 账号状态机只允许 `pending_email → active ↔ disabled`，最后一个管理员不能被降级或禁用；唯一已验证 active student 在部署修正或登录时成为管理员，待验证/禁用/多账号均不得误提升；管理员学生视图的开启、关闭、管理接口 403、学生接口有效角色和真实角色降级撤销全部 Session 也必须覆盖。
- 登录页必须覆盖“记住登录状态”默认关闭、显式勾选才提交 `remember_me=true`、页面声明不保存密码；后端覆盖普通浏览器会话 Cookie、30 天持久 Cookie、精确 IP 绑定及会话列表标识；Next.js Server Component 回归必须断言 Cookie 与 Nginx 清洗后的来源 IP 同时转发，缺失来源 IP 时不伪造。
- 管理员用户列表覆盖三种账号状态的中文语义标签、状态圆点与非纯颜色表达，不得渲染内部英文枚举；姓名、邮箱、学号以及中文/英文角色和状态搜索必须在服务端分页前作用于全部账号，`count/items` 使用同一筛选并显式断言 SQL `ESCAPE`。回归至少构造总数超过 100 的分页响应，证明后续页可访问、匹配总数准确且搜索/活跃度参数在翻页时保留；另覆盖页码上限、`page=999` 规范化、写后重新协调、普通页删除补位与末页收缩回退，禁止退回“只加载前 100 条再本地过滤”。
- 受众组合的全部、并集、交集和发布快照计算。
- 通知/作业删除覆盖未发布物理删除、活动定时任务取消、已发布归档删除、重复删除幂等、脱敏审计以及归档资源学生 404；正式提交与历史提醒不得被级联删除。
- 上海时区展示与 UTC 存储，公共截止和个人延期优先级；覆盖 NFR-005。
- 赛事阶段顺序、报名窗口、人数上下限、队伍锁定、队长转让、队伍目录隐私和自动分配最小队伍选择。
- 管理员删除队伍覆盖无历史提交物理删除、已有提交转 `dissolved` 保留壳、当前成员全部释放、取消资格元数据收口、常规读取消失、真实管理员/CSRF/原因校验和脱敏审计；历史提交、版本、评语与附件不得级联删除。
- 问卷标题/题目/同题选项校验、关闭后重新开启/再次关闭与归档终态、填写窗口、分题单选/多选、有限/不限提交次数、实名名单授权、零分母分题汇总和二维码 token 轮换。
- 提交至少一种内容、版本号递增、2 GiB 合计和附件上下文匹配。
- Markdown 清洗、外链协议、文件名规范化和扩展名白名单。
- Outbox 退避、最大次数、锁租约、幂等键与永久/临时 SMTP 错误分类。

## 集成测试重点

- 所有唯一、检查、外键和部分唯一索引实际生效。
- 并发双注册、双加入队伍、双版本提交和重复发布只有一个成功业务结果。
- 业务写入、审计和 Outbox 在同一事务提交；事务失败不得留下部分数据。
- Session 哈希、过期、撤销和 CSRF 校验使用真实数据库路径。
- multipart 初始化、分片恢复、完成、哈希不匹配、终止和孤立清理。
- 下载授权从真实业务引用反查，不能只凭 `file_id` 或上传人放行。
- Worker 使用 `SKIP LOCKED` 多实例领取不会重复完成任务。
