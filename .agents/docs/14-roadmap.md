# 路线图

路线图按依赖和风险排序，不按页面数量排序。每阶段只有在验收条件满足、文档同步和迁移可用后才能进入下一阶段。

## 阶段 0：权威文档基线

### 交付

- README、AGENTS、任务计划、项目记忆和全部产品/技术专题文档。
- 需求编号、页面路由、API、数据实体、测试矩阵和 ADR。

### 验收

- 文档链接有效，没有未决设计标记。
- 产品状态、权限、截止、错误和数据约束跨文档一致。
- 后续 Agent 不依赖聊天记录即可开始项目初始化。

## 首版之后

以下能力不进入上述首版，只有出现真实需求并新增 ADR 后评估：

- 校园 SSO、MFA 或外部 OAuth。
- 与现有官网的导航或数据集成、飞书双向同步。
- 多学校/多组织租户隔离。
- 评分、量规、排名、证书和公开作品页面。
- 恶意软件扫描、文件在线预览和通用课程内容管理。
- 独立消息队列、多节点高可用和移动 App。

任何后续能力不得破坏首版的私密评语、不可变版本、服务端授权和对象存储边界。
