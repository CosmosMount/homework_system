# 路线图

路线图按依赖和风险排序，不按页面数量排序。每阶段只有在验收条件满足、文档同步和迁移可用后才能进入下一阶段。

## 阶段 0：权威文档基线

### 交付

- README、AGENTS、任务计划、项目记忆和全部产品/技术专题文档。
- 需求编号、页面路由、API、数据实体、测试矩阵和 ADR。

### 验收

- 文档链接有效，没有未决设计标记。
- 产品状态、权限、截止、错误和数据约束跨文档一致。
- 后续 Agent 不依赖聊天记录即可开始项目初始化。

## 阶段 1：基础设施与工程骨架

### 交付

- `frontend/` Next.js、`backend/` FastAPI、`infra/` Compose 与 Nginx 基础结构。
- PostgreSQL、MinIO、API、Worker、Frontend 和 Nginx 健康检查。
- 统一配置、错误结构、请求 ID、日志、数据库会话、Alembic 和 CI 质量门。
- 基础深色设计令牌和页面骨架。

### 验收

- 一条命令启动本地开发环境，空库迁移到最新。
- Nginx 是唯一浏览器入口，PostgreSQL/MinIO 管理端口不公开。
- lint、类型、单元、迁移和 Compose 冒烟测试通过。

### 实施状态（2026-08-23）

- 前端、后端、首条 Worker 心跳迁移、Worker、固定版本镜像、Compose、Nginx 和 CI 已实现。
- 本机前后端 lint、格式、类型、14 个后端测试、3 个前端测试、生产构建和两类依赖漏洞扫描已通过。
- Windows 裸启动已验证 `/login`、根路径跳转、前端健康、前端 404、后端存活、统一后端 404，以及无 PostgreSQL 时安全返回 503；浏览器自动视觉检查因本机浏览器沙箱不可用而未执行。
- Compose/真实 PostgreSQL 迁移冒烟已写入 CI；当前 Windows 主机未安装 Docker，因此仍需在 Docker 主机或 CI 实际通过后，才视为阶段 1 全部验收完成并进入阶段 2。

## 阶段 2：认证与基础数据

### 交付

- `@hkust-gz.edu.cn` 邮箱注册、验证后直接激活、管理员禁用/恢复。
- Argon2id、服务端 Session、CSRF、密码重置、Session 管理和限流。
- 不阻塞登录的可选届次/方向、首个管理员命令、用户管理和审计。
- 验证与重置的 Outbox 邮件。

### 验收

- AUTH-T01～AUTH-T11、SEC-T01、SEC-T03 通过。
- 最后管理员保护、邮箱变更重新验证、禁用即时撤销会话有效。
- 安全 Cookie、同源策略和日志脱敏经浏览器与集成测试确认。

## 阶段 3：通知与工作台

### 交付

- Markdown 通知、附件、全体与可选届次/方向受众、草稿、定时发布、置顶和归档。
- 学生工作台、通知列表/详情、站内未读和更新提醒。
- 通知邮件 Outbox、管理员邮件状态与人工重试。

### 验收

- NEWS-T01～NEWS-T06、MAIL-T01～MAIL-T03 和 Markdown 安全测试通过。
- SMTP 停止时站内发布成功，恢复后积压可清空。
- 非受众通过直接 ID访问仍为 404。

## 阶段 4：作业、上传与私密评语

### 交付

- 作业草稿/发布/关闭/归档、固定受众快照、公共截止和个人延期。
- MinIO 16 MiB 分片上传、恢复、完成校验、短时下载和孤立对象清理。
- 个人不可变提交版本、最新指针、私密评语和管理员提交统计。
- 管理员标记/取消优秀作业，以及作业受众在对应作业内查看优秀版本。

### 验收

- HW-T01～HW-T13、SHOW-T01～SHOW-T05、FILE-T01～FILE-T09 通过。
- 2 GiB 边界、并发幂等、截止发生在上传期间和他人文件引用均按规范处理。
- API/Worker 内存不随完整文件大小增长。

## 阶段 5：校内赛、报名与团队提交

### 交付

- 赛事阶段、报名、自助建队、邀请码、队长、人数约束、锁队和管理员纠错。
- 多赛题、队长正式提交、团队版本历史和团队私密评语。
- 管理员赛事/队伍/提交统计和阶段 Worker。

### 验收

- COMP-T01～COMP-T04、TEAM-T01～TEAM-T07 通过。
- 并发双加入、一赛一队、非队长提交、人数不足和管理员豁免均由数据库与 Service共同保证。
- 页面和 API 不出现分数、排名或公开评语。

## 阶段 6：生产运维加固

### 交付

- 校内 HTTPS、固定镜像、容器资源限制、结构化日志、指标和独立告警。
- PostgreSQL/MinIO 加密备份、恢复脚本、引用对账和恢复演练。
- 300 账号、100 浏览会话、20 并发上传的压力测试和容量报告。
- 完整安全复查、依赖扫描、秘密扫描和发布/回滚手册。

### 验收

- 非上传 API P95 小于 500 ms，错误率低于 1%。
- RPO 24 小时、RTO 4 小时的隔离恢复演练通过。
- 证书、备份、Outbox、磁盘和 Worker 心跳都有独立告警。

## 首版之后

以下能力不进入上述首版，只有出现真实需求并新增 ADR 后评估：

- 校园 SSO、MFA 或外部 OAuth。
- 与现有官网的导航或数据集成、飞书双向同步。
- 多学校/多组织租户隔离。
- 评分、量规、排名、证书和公开作品页面。
- 恶意软件扫描、文件在线预览和通用课程内容管理。
- 独立消息队列、多节点高可用和移动 App。

任何后续能力不得破坏首版的私密评语、不可变版本、服务端授权和对象存储边界。
