# 按钮浅蓝化与管理员入口视觉优化计划

## 背景

当前系统已经完成蓝白主题，但主操作仍偏深，管理员通知、作业和赛事列表页的“新建”入口只是普通矩形链接，层级、圆角和交互反馈不足。用户希望按钮更浅蓝，并改善“新建通知”“新建作业”等入口。

## 必要性

- 主操作需要与浅色页面形成清晰但柔和的视觉焦点。
- 链接形式的创建入口必须具备按钮语义、触控尺寸、圆角和悬停/键盘反馈。
- 共享按钮样式应避免各页面继续复制不一致的 Tailwind 类。

## 修改范围

- 新增浅蓝主操作令牌和统一按钮/按钮链接样式，保留状态标签使用的深蓝色。
- 将学生端筛选、上传、管理员保存和新建入口接入共享样式。
- 优化管理员通知、作业、赛事列表头部的创建入口，增加明确的“新建”图标和悬停层次。
- 同步设计系统、当前任务和变更记录；不修改业务 API、权限、数据库或迁移。

## 验证方式

- 运行前端全量 Vitest、ESLint、严格 TypeScript 和生产构建。
- 检查管理员创建入口具有可读名称、链接地址、圆角、浅蓝背景和键盘焦点。
- 仅暂存本任务和此前已完成但尚未提交的项目实现，分职责创建多个提交后推送当前分支。

## 本次执行结果（2026-08-26）

- 管理员通知、作业和赛事列表页统一复用管理端命令栏结构，创建入口使用紧凑的浅蓝按钮链接（`h-9`、`rounded-lg`、键盘焦点和悬停反馈），保留加号图标与原有路由。
- 新增 `AdminPageHeader` 和 `commandButtonClassName`/`commandLinkClassName`，表单主按钮的既有尺寸与样式保持不变。
- 修复 CI 严格 Mypy 对认证测试上下文和通知测试发送器属性推断的 3 个错误，仅调整测试类型标注，不改变运行时业务逻辑。
- 验证完成：后端定向测试 14 项、严格 Mypy 127 个源文件、Ruff 检查/格式；前端 14 个测试文件 42 项、ESLint、严格 TypeScript 和 Next.js 生产构建全部通过。
