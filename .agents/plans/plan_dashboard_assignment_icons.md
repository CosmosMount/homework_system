# 工作台作业可见性与原子图标修复计划

## 背景

当前运行中的 Backend/Worker 镜像早于管理员学生视图作业预览修复启动，导致已发布作业在学生视图工作台的“近期作业”区域可能仍显示为空。共享侧栏此前以首字母或中文单字充当图标，品牌标识和身份卡也存在同类文字占位。

## 目标

- 确保已发布且当前账号可见的作业出现在工作台“近期作业”区域，并覆盖管理员学生视图的临时受众预览。
- 以统一的内联 SVG 原子图标替换导航、品牌、身份卡、视图切换、退出和抽屉按钮中的文字占位。
- 保持现有权限、受众快照、数据库结构、Markdown 清洗和业务流程不变。

## 实施范围

1. 保留现有 Dashboard/Assignment 服务端受众规则，补充工作台作业聚合回归测试并重建 Backend/Worker 镜像。
2. 新增无依赖的 SVG 图标原子组件，在共享导航和认证壳层统一使用语义图标；可见文字标签继续作为导航名称和无障碍文本。
3. 运行前端与后端定向质量门，重建并重启相关 Compose 服务，验收健康接口和 5000 端口。

## 验证

- 前端 Vitest、ESLint、严格 TypeScript、Next.js 生产构建。
- 后端作业/认证定向测试、Ruff、严格 Mypy。
- Compose 六服务健康，`/health/live`、`/health/ready`、`/health/worker`、`/nginx-health` 和 5000 端口返回 200。
- 检查工作区差异、提交独立修复 commit，并确认无数据库迁移。
