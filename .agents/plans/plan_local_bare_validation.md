# Windows 本机裸运行验证与首次提交计划

## 问题背景

阶段 1 工程骨架已经实现并通过静态质量门，但当前 Windows 主机没有 Docker，用户希望先直观看到前端效果和后端基础响应，同时明确将 `.agents/` 权威文档纳入 Git 首次提交。PostgreSQL、MinIO、Nginx、Worker 与完整 Compose 集成留到 Linux 服务器验证。

## 现有结构与可复用能力

- `frontend/` 已安装锁定依赖，可使用 Next.js 开发服务器独立运行 `/login` 与 `/health`。
- `backend/.venv` 已安装锁定依赖，可使用 Uvicorn 独立运行 `/api/v1/health/live`；数据库未启动时 `/ready` 预期返回统一 503，不视为本次失败。
- 前后端 lint、类型、单元测试、生产构建和依赖审计已通过，不需要为展示伪造认证或业务数据。
- 仓库尚无提交，当前项目文件均为未跟踪状态；`.gitignore` 已排除 `.env`、虚拟环境、`node_modules`、`.next`、缓存和构建元数据。

## 计划执行

1. 启动 FastAPI 裸进程，验证存活接口、请求 ID、统一 404，以及未连接 PostgreSQL 时就绪接口安全失败。
2. 启动 Next.js 裸进程，验证根路径跳转、登录页、前端健康路由和不存在页面。
3. 使用本地浏览器检查登录页的桌面与移动布局、禁用登录按钮、校园邮箱字段和“认证尚未接入”提示；若浏览器连接不可用，则保留 HTTP 与组件测试证据并明确说明。
4. 停止本次启动的两个开发进程，不在后台遗留服务。
5. 更新任务、变更记录和项目记忆，记录 Windows 裸测通过范围以及 PostgreSQL、MinIO、Nginx 留待 Linux 的边界。
6. 检查待提交文件和常见秘密格式，确认 `.agents/` 被包含而依赖/缓存/真实环境文件被排除，然后创建一次 Git 首次提交。

## 影响范围

- 运行态：仅临时监听本机 `127.0.0.1:3000` 与 `127.0.0.1:8000`。
- 文档：更新 `.agents/tasks/`、`16-changelog.md` 和 `project_baseline.md` 的验证状态。
- Git：提交当前阶段 0～1 的源码、配置、锁文件、迁移、测试和全部 `.agents/` 权威内容。

## 不在范围内

- 不安装或启动 PostgreSQL、MinIO、Nginx、Worker、Docker 或 Compose。
- 不执行真实数据库迁移，不修改业务源码，不实现注册、登录或其他业务能力。
- 不创建 `.env`，不提交秘密、依赖目录、缓存、测试截图或构建产物。

## 验证与完成标准

- FastAPI `/api/v1/health/live` 返回 200 和有效请求 ID；无数据库时 `/ready` 返回统一 503 且不泄露连接信息。
- Next.js `/` 跳转 `/login`，`/login` 与 `/health` 返回 200，未知页面返回 404。
- 登录页视觉与当前设计规格一致，或明确记录浏览器工具限制。
- 两个本地进程在验证后均停止。
- `git status --ignored` 证明依赖与缓存未纳入，暂存区包含 `.agents/` 且不含真实 `.env`。
- 提交成功，提交后工作区干净；提交说明概括阶段 0～1 基线与 Windows 裸测。

## 执行结果（2026-08-23）

- Next.js 与 FastAPI 裸启动成功，前端页面、跳转、健康、404 及后端存活、请求 ID、统一 404 均符合预期。
- 裸测发现数据库 DNS/套接字错误未被健康服务识别，已最小修复为 503 并新增两项回归测试；14 个后端测试全部通过。
- 未启动 PostgreSQL 时 `/ready` 返回 503 `DEPENDENCY_UNAVAILABLE`，响应不包含连接串或数据库地址。
- 本地浏览器自动化因 Windows 沙箱初始化失败而无法执行；已向用户打开本地预览，视觉截图留待可用浏览器环境。
- PostgreSQL、MinIO、Nginx、Worker、Compose 和真实迁移按用户要求留到 Linux 服务器验证。
