# Markdown 预览与蓝白圆角主题计划

## 问题背景与本质原因

- 管理员作业编辑页的“Markdown 作业说明”只有原始 textarea，没有渲染预览；截图中的 `#`、`##` 和列表符号因此按纯文本显示。
- 后端已通过统一 Markdown 清洗管线生成 `description_html`，学生作业详情等页面也已使用 `SafeHtml`，缺口在管理员编辑器的预览体验，不是数据库或发布 API 问题。
- 当前全局令牌仍是深色黑底、红色主强调和方形边框，与用户要求的蓝白主色及更多圆角不一致。

## 现有结构与可复用能力

- `backend/app/core/markdown.py` 是唯一 Markdown 渲染与清洗管线，前端 `SafeHtml` 负责展示已清洗 HTML；不新增第二套 Markdown 解析器。
- `AssignmentEditor` 已同时持有原始 Markdown 和服务端返回的 `description_html`，保存成功后可立即刷新预览。
- `frontend/app/globals.css` 集中定义颜色、焦点和富文本样式；多数页面通过 CSS 变量和共享表单类使用这些令牌，适合全局换肤。

## 必要修改

1. 增加可复用的 Markdown 预览面板，复用 `SafeHtml` 和后端清洗结果；作业编辑页同时展示编辑区与“已保存渲染预览”，新建或尚未保存时给出明确提示。
2. 补充管理员作业页面回归测试，确认保存的 `description_html` 以标题、列表等 HTML 结构渲染，而不是显示 Markdown 标记文本；保留危险 HTML 不执行的既有测试。
3. 将全局颜色令牌切换为蓝白配色，调整页面背景、表面、文本、边框、强调、状态和焦点色，确保文字对比度满足 WCAG 2.1 AA。
4. 在全局基础样式和共享控件中增加一致的圆角、轻微阴影/层次和蓝色交互反馈；不改变权限、状态、API、数据结构或导航。

## 影响与不修改范围

- 对应需求为 HW-001、HW-006、NEWS-001、COMP-004、SUB-006，以及 NFR-004、NFR-011。
- 预览只展示服务端已经清洗的 HTML，不接受原始 HTML，也不把前端原始 Markdown 直接注入 DOM。
- 不新增依赖，不新增 API 或数据库迁移；编辑器中的未保存文本仍以 textarea 为准，预览明确标注为最近一次保存版本。
- 主题调整覆盖全局 CSS 令牌和共享基础样式，不逐一改变业务文案或权限入口。

## 验证与上线

1. 运行 Markdown/富文本、管理员页面及完整 Frontend Vitest。
2. 运行 ESLint、严格 TypeScript 和 Next.js 生产构建。
3. 用真实 Chromium 检查作业编辑页的渲染预览、蓝白背景、圆角容器和键盘焦点。
4. 重新构建并替换 Frontend，确认六个常驻服务健康和 5000 端口页面可访问。
5. 更新设计系统、页面规格、测试策略、变更记录、当前任务、完成记录和项目基线。
