# 物资标签二维码优先排版

## 背景与范围

用户反馈左侧二维码定位图形异常、右侧留白偏多，要求先保证二维码空间再安排名称。关联 MAT-007。现有 240×96 点标签把二维码强制缩放到 88 点；模块数加静区不能整除 88 时，模块宽度不均，可能影响热敏打印定位图形。

## 实施与验证

保留现有纸张尺寸及打印方向；按实际二维码模块数选择标签高度能容纳的最大整数点阵倍数，保留四模块静区和纸边余量，禁止缩放或文字覆盖。名称只使用二维码之后的剩余区域，换行省略。无法提供至少两点模块时明确提示链接过长，不输出低质量码。用实际长短入口 URL 验证像素矩阵、静区与文本边界，执行物资回归、TypeScript 和 ESLint。

无 API、数据迁移或二维码内容变化；未部署，实体偏移仍须设备验收。

## 完成结果

已完成整数点阵、静区与左侧纸边保护、独立文字裁剪和超密链接提示；移除旧二维码缩放渲染。两文件 8 项测试、TypeScript、范围 ESLint 通过。无 API 或迁移，未部署；实际走纸偏移与扫码仍待现场验收。
