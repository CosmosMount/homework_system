# 物资批量登记排序修复

## 背景、必要性与影响

MAT-001、MAT-002、MAT-007：批量登记共用时间戳，台账按更新时间和 UUID 排序，UUID 随机部分使同毫秒的编号乱序；领用归还还会改变位置。全选打印继承台账顺序。

## 实施

1. Repository 在分页前按创建时间倒序、去除末尾数字编号的名称、末尾编号数值升序、完整名称及 UUID 排序。批量后缀为 `-1` 至 `-100`，不按字符串编号排序。旧物资直接生效，无需迁移或回填。
2. 保留手动勾选顺序与打印队列；按页全选继承台账顺序。
3. 隔离 PostgreSQL 回归覆盖批量、跨页、数字边界、更新时间变化；运行前端物资与打印测试。
4. 更新需求、API、页面、测试、决策、变更与任务记录；保持既有工作区改动。

## 验证与风险

不改写业务数据或二维码，不改变鉴权与领用事务；无数据库迁移。实物打印需硬件验收，源码通过不代表已上线。

## 完成结果

源码、文档与回归已完成。隔离 PostgreSQL 空库迁移到现有 head 后运行后端 9 项通过，前端物资 5 项通过，Ruff 与格式检查通过。临时测试容器已清理；无新增迁移，尚未部署生产或验证实体打印。
