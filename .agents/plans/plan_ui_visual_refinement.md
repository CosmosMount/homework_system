# 共享布局与视觉层次细化计划

## 背景

当前系统已完成纯白背景和蓝白配色，但页面仍偏“工具表单”风格：导航图标使用符号、用户身份缺少视觉锚点、认证表单与主内容区的层级不够明确，卡片间的边界和悬停反馈也不够统一。

## 目标

- 在不改变业务流程的前提下，强化品牌头部、身份区、导航 active 状态和内容卡片层次。
- 让认证页、学生端和管理员端共享同一套白色表面、蓝色强调、圆角和轻阴影语言。
- 保持纯白页面根背景、现有权限导航、Markdown 安全渲染和移动端抽屉行为。

## 修改范围

1. 细化全局排版、滚动条、面板阴影和控件状态，建立可复用的视觉令牌。
2. 优化共享侧边栏：品牌标识、用户身份卡、首字母导航图标、active/hover 状态和学生视图入口。
3. 优化认证壳层：在右侧表单周围增加清晰的白色卡片容器，并改善移动端品牌区。
4. 不修改 API、权限、数据库、Markdown 清洗或业务状态机；仅调整共享前端表现层。

## 验证

- 运行前端 Vitest、ESLint、严格 TypeScript 和 Next.js 生产构建。
- 重新构建 Frontend，重启 Frontend/Nginx，检查 Compose 健康和 5000 端口。
- 更新设计系统、变更记录、当前任务和完成记录。
